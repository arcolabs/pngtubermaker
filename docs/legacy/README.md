# Legacy Documents (Historical)

Everything in this directory is **historical**: dated plans, task lists,
launch checklists, deployment explorations, and postmortems from the
single-app era (mostly 2026-02 → 2026-08). They are kept for archaeology —
to answer "why was it done this way?" — not as instructions.

- **Do not treat anything here as current truth.** Active project context
  lives in `docs/context/` (see its README for ownership rules).
- Several documents describe deployments (Dokploy, K3s, Coolify, Zeabur VPS
  purchases) that were explored and abandoned; the current deployment
  contract is in `docs/context/operations.md`.
- Some documents contain machine-specific paths, IP addresses, or personal
  workflow notes from the original author's environment. They are historical
  records; never copy such references into active context, code, or config.
- If a fact here is still true and still matters, promote it into
  `docs/context/` (rewritten, verified against the code) rather than linking
  back here.
